Reaction Diffusion (Gray-Scott) — guerrilladigital\n**Technique:** Concentration field reaction-diffusion; turing pattern crystallization. **Algorithm core:** 64x36 grid double-buffered; per step, per cell: `lap_a = up+dn+left+right - 4a; lap_b = ...; abb=a*b*b; a2 = a + dA*lap_a - abb + f*(1-a); b2 = b + dB*lap_b + abb - (k+f)*b` with `dA=1.0,dB=0.5`, `f=0.01+knob1*0.05 + env*0.02 (cap 0.08)`, `k=0.04+knob2*0.03 + sin(t*0.15)*0.01 + env*0.01`, `steps=1..3`. Seed 3x3 spots of B=1; reseed full grid every 4 beats or min 2s; capture echo snapshot (alpha 220) before wipe; continuous small seed every 10 frames; B>0.08 → circle radius 2+4b, color `(color_base+color_offset+b*0.3+sin(t*0.3)*0.08)`; rotate ±0.035rad. **Primitives:** → half-res (640x360) fragment shader reading the *previous* target as the U/A/B concentration fields, running the discrete `a/g + dA*laplace - abb + f*(1-a)` per pixel with named uniforms f,k; a max()/decay composite into a second target. Trigger/frame reseed = draw black + random B-spots via a uniform seed point. Echo snapshots → keep a third target as a retained ghost (fade alpha). **Knobs:** k1 feed f, k2 kill k, k3 steps/res, k4 hue, k5 feedback decay. **Effort: L** (first GPU RD — hardest part is correct discrete Laplacian + no self-amplify trap). **Changes:** CPU grid → GPU fragment; veil → decay shader; 100-sample env → rms/bands; the win is *full quality at 60fps instead of a 64x36 dot-grid*.\n\n### 2. Hertsi — twang69\n**Technique:** minimal generative horizontal line-ribbon field. **Algorithm core:** fill bg; 12 lines, thickness `2+2*i`; line at y centers with `start_x=(xres-line_length)//2`; wave `total = sin(rx*freq*aud_vary + phase0) + wave2 + wave3 + ripple` where base `freq=0.02`, `wave2_amp=complexity*0.5 @ 1.5*freq + π/2`, `wave3_amp=(complexity-0.5)*1.5 @ 0.7*freq + π*0.3`; amplitude `max_wave_height=min(spacing//2,15) * knob3 * (audio_level or trigger full)`; audio lifts freq up to 20% and thickness ~10%; trigger fires a decaying 30-frame random sine/cosine ripple. Each line drawn as upper/lower-edge polygon ribbon (`filled_polygon`+AA). **Primitives:** immediate `line()`/polyline filled ribbons; no feedback needed (it's a static-pattern mode) — could add a subtle trails pass. **Knobs:** k1 line length, k2 spacing (inverted), k3 wave amplitude, k4 complexity, k5 fg/bg `_hue_to_rgb(h) / +0.5` complement. **Effort: S.** **Changes:** audio_in abs-mean → `rms_left/right` smoothed; garbage-collected polygon → our `mesh` closed ribbon or per-line polyline; AA via line width; hue complement via `eyesy.palette`/define_palette instead of custom `_hue_to_rgb`.\n\n### 3. Flow Field Drift — guerrilladigital\n**Technique:** particle drift through a layered-sine flow field. **Algorithm core:** 22x13 flow grid; `angle = 2*sin(fx+z*0.3)+2*cos(fy+z*0.2)+1.5*sin(x*0.1*s+y*0.2*s+z*0.15)+1.0*sin(fx*0.7+z)+1.0*cos(fy*0.5+z*0.8)` with `fx=x*0.3*noise_scale`; particles steer by 360-entry cos/sin tables, `speed_mult=base*(0.7+env*1.2)`, edge respawn; trigger shockwave `noise_amp=1+2*(shock/15)`; no veil (color accumulates). **Primitives:** Two viable homes: (a) mesh point/stroke field — 300-600 point meshes updated per frame (cheap), or (b) half-res shader computing the field and advecting via prev-target warp — matches the 'steady advection' look with decay. Ship (a) first as half-res target with upscale; k1 density vs size, k2 noise_scale, k3 base speed, k4 hue, k5 bg. **Effort: M.** **Changes:** precomputed 360-entry tables → native math or 1024-sample u_audio; 600 circles overdraw → point-mesh; sharpen with the feedback zoom.\n\n### 4. Strange Attractor (Lorenz) — guerrilladigital\n**Technique:** chaotic ODE flow traced as a persistent trail. **Algorithm core:** `dx=s·(y-x)dt; dy=(x(ρ-z)-y)dt; dz=(xy-βz)dt`, `dt=0.005`, `σ=10+sin(t*0.07)*2+env*3`, `ρ=28+sin(t*0.05)*5+env*20+rho_spike(trigger=20 decay 0.85)`, `β=8/3+sin(t*0.04)*0.5`; integrate 120-200 substeps/frame into a 2500-pt ring buffer; project with scale 10·(0.6+knob1*2)+env*5, XY rotate + YZ pitch; color by z/50 + time + color_base; draw as 100-pt line segments (thickness 1-2); head dot radius 3..7. **Primitives:** → single 2500-vertex line-strip **mesh** (well under 8192), re-created per frame from the ring buffer; half-res target + upscale for the decay-linger; head dot = small circle overlay. **Knobs:** k1 rotation speed+zoom, k2 thickness (1-2), k3 visible trail length (500-2500), k4 hue, k5 bg. **Effort: S** (the in-repo `phosphor` already nails this idiom). **Changes:** no veil — decay shader; σ/ρ/β from spring env + bands; deterministic random; save/restore trail.\n\n### 5. Barnsley Fern IFS — guerrilladigital\n**Technique:** iterated-function-system fractal. **Algorithm core:** 4 affine maps with audio-morphed coefficients + stereo wind: probabilities `p2=0.85-env*0.12`, `p3=0.01+p2+rem*0.5`; stem `(0,0.16y)` 1%; body `f2: a=0.85,b=0.04*curl+envL*0.03,c=-0.04*curl-envR*0.03,d=0.85, tx=tilt*0.15,ty=1.6`; leaflets `f3: a=0.2+envL*0.08, b=-0.26c, c=0.23c, d=0.22+envL*0.06` / `f4: a=-0.15-envR*0.08, b=0.28c, c=0.26c, d=0.24+envR*0.06` with `curl=0.6+sin(t*0.15)*0.4+env*0.35`, `tilt=sin(t*0.5)*0.1+(envR-envL)*0.4`; 500-3000 pts/frame over 1-3 origins, feedback-zoom ~2%; trigger resets origins. **Primitives:** Lua point-generation → small-circle/dot mesh (a few thousand pts), feedback zoom via our warp-pass prev-target scale; per-origin offsets. **Knobs:** k1 density (500-3000), k2 fern count (1-3), k3 fade alpha (3-27), k4 hue, k5 bg. **Effort: M.** **Changes:** 100-sample stereo envelope → our real L/R FFT/envs keep the wind-side illusion; veil→decay shader; shuffle-=stereo module is strictly richer.\n\n### 6. Cymbal Cymatics — guerrilladigital\n**Technique:** circular-plate Bessel standing-wave nodal patterns. **Algorithm core:** `V(r,θ)=J_n(k·r)·cos(m·(θ+θ0))` with `k=n·π`; zero-crossing contour detection scanned both angularly (`J_n·cos(mθ)` sign-flip per radial ring) and radially; LUT-interpolated `J_n` (orders 0-8) + trig tables; mode targets `target_n=knob1*7+1+envL*1.5+drift`, `target_m=knob2*8+envR*1.5+drift`, spring-interp `current+= (target-current)*0.08`; trigger snaps to (6,6); feedback-zoom 1310/738 with alpha 250; dual-pass glow (dim + bright core dots); three pulsing center circles. **Primitives:** → half-res fragment shader evaluating `sign(J_n(k·r)·cos(mθ))` per pixel → nodal-line glow; plate center/radius as uniforms; center pulse circles immediate. **Knobs:** k1 radial mode n, k2 angular m, k3 sharpness (2-15), k4 hue, k5 bg. **Effort: L** (Bessel J_n = series `Σ(-1)(x/2)^(2k+n)/(k!(k+n)!)` in GLSL — feasible, or precompute a 9x50 J_n LUT and float-index it in the shader fragment). **Changes:** CPU LUT + Python Bessel → fragment field; feedback-zoom → prev-target warp+decay; envs → rms/bands.\n\n### 7.
